## О проекте
Этот проект был разработан в сентябре-октябре 2022 года.
Выложен на GitHub [06.12.2025] для демонстрации опыта работы с Django.

CRM Market - Что это?
Это Django-приложение для управления интернет-магазином (CRM система). Это платформа для управления продажами, товарами, клиентами и отчетностью.
Основные модули:

📦 Product - управление товарами (добавление, редактирование, каталог)

🏪 Shop - функционал самого магазина (корзина, заказы, оплата)

👤 Account - система аккаунтов (регистрация, авторизация, профили пользователей)

📊 Report - генерация отчетов (продажи, статистика, аналитика)

🔌 API - REST API для интеграции с другими системами

Технологии:

Backend: Django (Python)

Frontend: JavaScript (92.5%), CSS

Database: SQLite
